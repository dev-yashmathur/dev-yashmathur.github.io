The silent cost

Everyone thinks about RAM and GPUs when they think about the cost of AI. The cost to your storage is the one that gets missed, and if you use more than one agent, so does keeping them in sync.

Storage

Questions

Is Portée free?

Yes. Portée is a free download for macOS.

Which coding agents does Portée support?

Claude Code, Codex, Cursor and OpenCode. Portée detects which of them are installed on your Mac and where they keep their data.

How much disk space do Claude Code and other coding agents use?

It depends on how much you use them: sessions, caches and app data pile up over time, often into gigabytes. Portée shows the disk and memory each agent is using right now, so you can see the real number for your Mac.

Will Portée delete anything on its own?

No. The Storage view groups what can be cleaned up for each agent, and nothing is removed until you review it and choose what goes.

How do I use the same MCP servers and skills in every agent?

Add an MCP server, skill, tool or hook to Portée’s catalog once, then choose which agents to sync it to. Existing configs can be adopted into the catalog, and TOML files are edited in place so your comments and formatting survive.

Can I search my old Claude Code and Codex sessions?

Yes. Portée searches past sessions across all four agents by the words you remember, then opens the one you need so you can carry on instead of starting over.

Does session search send my data anywhere or use tokens?

No. Search runs on a local index on your Mac, so it costs no tokens and your sessions never leave your machine.

Why does macOS warn me the first time I open it?

Portée is not yet notarized by Apple. On first launch, right-click the app and choose Open; after that it opens normally.
